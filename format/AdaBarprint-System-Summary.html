1 สรุปภาพรวมโปรแกรมและ Tech Stack

AdaBarprint (v0.2.1) เป็นระบบออกแบบและสั่งพิมพ์ป้ายราคา / บาร์โค้ด / Pre-Print สำหรับ POS (AdaPos+) ที่รวมทั้ง Desktop App (Tauri v2) และ Web Server (Rust Axum + React/Vite) เข้าด้วยกัน โดยอ่านข้อมูลสินค้า/ราคา/โปรโมชันจากฐานข้อมูล db/AdaAccD.db และจัดเก็บแม่แบบป้าย การผูกเครื่องพิมพ์/ถาด และประวัติการพิมพ์ไว้ในฐานข้อมูลเดียวกันผ่าน SQLite WAL Mode

6 ไดร์เวอร์เครื่องพิมพ์และกลไกสเกล 1:1 mm

1. Windows Direct Print (post_windows_direct_print)
  • จับภาพหน้ากระดาษ/ม้วนจาก Frontend ด้วย SVG-to-Canvas ความละเอียด 2x (192 DPI)
  • ป้องกัน Race Condition ด้วย WINDOWS_PRINT_LOCK Mutex
  • รัน PowerShell PrintDocument ตั้งค่า PaperSource (ถาด) และ PaperSize แบบ GDI-DEVMODE ต่อ Job (ไม่รบกวนค่า Spooler กลาง)
  • สเกลแม่นยำ 1:1 mm: ตั้ง e.Graphics.PageUnit = Millimeter วาดขนาด paperWidthMm × paperHeightMm เต็มแผ่น (x=0, y=0) เพื่อไม่ให้แถวล่างบนฟอร์ม Pre-Print เยื้องสะสม
  • รองรับส่งพิมพ์ออกเครื่อง PDF เสมือน (บันทึกไฟล์อัตโนมัติลงโฟลเดอร์ exports/)
2. Thermal Roll & LAN Drivers (print_drivers/mod.rs)
