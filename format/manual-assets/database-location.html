ก่อนเริ่ม: ฐานข้อมูลสองไฟล์วางไว้ที่ไหน

เครื่อง Standalone ใช้ AdaBarprint ได้โดยไม่ต้องติดตั้ง POS แต่ต้องตั้งค่าการดาวน์โหลดข้อมูลให้เรียบร้อยก่อนเข้าสู่ระบบใช้งาน

ไฟล์ใช้เก็บอะไรตำแหน่งมาตรฐานเมื่อติดตั้งใหม่
AdaBarprint.dbแบบป้าย การตั้งค่า เครื่องพิมพ์ ตารางงานและประวัติ ระบบสร้างและจัดการไฟล์นี้เอง ไม่มีช่องเลือกพาธในหน้าจอC:\ProgramData\AdaPos6.0\AdaBarprint\Data\AdaBarprint.db
AdaAccD.dbสินค้า ราคา โปรโมชั่นและผู้ใช้ที่ดาวน์โหลดมา สำหรับเครื่อง Standalone เลือกพาธปลายทางได้C:\ProgramData\AdaPos6.0\AdaBarprint\Data\AdaAccD.db

ตำแหน่งข้างต้นคือค่าเริ่มต้นของชุดติดตั้งบน Windows ที่ใช้ ProgramData บนไดรฟ์ C ไม่ใช่โฟลเดอร์ที่วางไฟล์ติดตั้ง EXE และไม่จำเป็นต้องมีไดรฟ์ D

เครื่องใหม่ ไม่มี POS: เริ่มแบบ Standalone

  1. ติดตั้งและเปิด AdaBarprint ระบบสร้างฐานการตั้งค่าของตัวเองให้ ไม่ต้องคัดลอก AdaBarprint.db จากเครื่องอื่นหากเริ่มใช้งานใหม่
  2. เปิดหน้าแหล่งข้อมูล เลือก เครื่องแยกจาก POS — ดาวน์โหลดข้อมูลเอง
  3. ในช่อง ไฟล์ฐานข้อมูลสำหรับดาวน์โหลด ใช้ตำแหน่งมาตรฐานด้านบน หรือระบุพาธเต็มที่ต้องการ เช่น D:\POS6\AdaBarprint\db\AdaAccD.db เมื่อเครื่องนั้นมีไดรฟ์และสิทธิ์เขียนที่ตำแหน่งนี้
  4. กรอกการเชื่อมต่อ API2PSMaster รหัสตัวแทน สาขา รหัสเครื่องและ API Key ตามที่ผู้ติดตั้งได้รับ ตั้งรอบดาวน์โหลดเป็น 60 นาที โดยยังไม่ต้องกรอก PIN บนหน้าหลัก
  5. กด บันทึกการเชื่อมต่อ กรอก PIN ในหน้าต่างยืนยันแล้วกด ยืนยันบันทึก จากนั้นกด ดาวน์โหลดข้อมูลตอนนี้ และยืนยัน PIN อีกครั้ง ระบบสร้างฐานสินค้าในพาธที่เลือกและดาวน์โหลดข้อมูลลงไฟล์นี้ เมื่อสำเร็จจึงเข้าสู่ระบบด้วยบัญชีผู้ใช้ที่ดาวน์โหลดมา

ไม่ต้องนำฐานสินค้าของเครื่อง POS มาวางก่อน สำหรับการตั้ง Standalone ใหม่ที่ดาวน์โหลดจาก API ได้ และห้ามใช้ฐานที่ POS กำลังใช้งานเป็นปลายทางดาวน์โหลด

นำฐานเดิมไปเดโมหรือย้ายเครื่อง

หากต้องการใช้แบบป้ายและข้อมูลเดิม ให้ผู้ติดตั้งเตรียมสำเนาฐานข้อมูลที่สมบูรณ์ก่อนย้าย วาง AdaBarprint.db ในโฟลเดอร์ Data มาตรฐานด้านบน ส่วน AdaAccD.db วางในตำแหน่งที่ต้องการแล้วกรอกพาธให้ตรงในหน้าแหล่งข้อมูล ตรวจเครื่องพิมพ์ การเชื่อมต่อและ PIN ใหม่บนเครื่องปลายทางก่อนใช้ และปิด Auto ไว้ระหว่างเตรียมเครื่อง ไม่คัดลอกไฟล์ฐานทับขณะที่โปรแกรมหรือตัวทำงานเบื้องหลังกำลังใช้งานอยู่

กรณีใช้เครื่องเดียวกับ POS

เลือก ใช้ฐานข้อมูลของ StoreFront และระบุพาธ AdaAccD.db ที่ POS ใช้จริง จากนั้นตรวจสอบการเชื่อมต่อและบันทึก โหมดนี้อ่านฐานของ POS โดยไม่ดาวน์โหลดทับ ส่วน AdaBarprint.db ยังเป็นฐานของโปรแกรมแยกต่างหาก
